# Справочник горячих клавиш (VS Code)

Проект «Справочник горячих клавиш» предназначен для быстрого поиска и использования сочетаний клавиш в редакторе VS Code. Он помогает ускорить работу с файлами, текстом, навигацией и терминалом, а также позволяет настраивать собственные комбинации.

## Категории горячих клавиш

- Файлы и навигация
- Редактирование текста
- Поиск и замена
- Работа с терминалом

## Основные сочетания клавиш в VS Code

| Действие | Сочетание клавиш (Windows/Linux) | Сочетание клавиш (macOS) | Категория |
| --- | --- | --- | --- |
| Открыть файл по названию | `Ctrl + P` | `Cmd + P` | Файлы и навигация |
| Перейти к строке | `Ctrl + G` | `Cmd + G` | Файлы и навигация |
| Закомментировать строку | `Ctrl + /` | `Cmd + /` | Редактирование текста |
| Дублировать строку | `Shift + Alt + ↓` | `Shift + Option + ↓` | Редактирование текста |
| Найти в файле | `Ctrl + F` | `Cmd + F` | Поиск и замена |
| Заменить в файле | `Ctrl + H` | `Cmd + H` | Поиск и замена |
| Открыть встроенный терминал | `` `Ctrl + ` `` | `` `Cmd + ` `` | Работа с терминалом |
| Переключить фокус на терминал | `Ctrl + ` `` ` | `Cmd + ` `` | Работа с терминалом |

> Примечание: в macOS символ `` ` `` (backtick) находится на той же клавише, что и тильда `~`.

## Пример настройки собственной комбинации

Чтобы задать своё сочетание клавиш в VS Code, нужно добавить правило в файл `keybindings.json`. Ниже — пример, который назначает `Ctrl + Alt + S` на команду «Сохранить все файлы»:

```json
[
  {
    "key": "ctrl+alt+s",
    "command": "workbench.action.files.saveAll",
    "when": "editorTextFocus"
  }
]
