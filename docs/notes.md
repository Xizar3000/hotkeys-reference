# Мои заметки по Git и Markdown

## Основные команды Git

- `git status` — показывает текущее состояние репозитория.
- `git add .` — добавляет все изменённые файлы в индекс.
- `git commit -m "Сообщение"` — фиксирует изменения локально.
- `git push` — отправляет коммиты на GitHub.

## Пример выделения текста

- **Жирный текст** делается с помощью двух звёздочек: `**текст**`.
- *Курсив* — одной звёздочкой: `*текст*`.
- ~~Зачёркнутый текст~~ — двумя тильдами: `~~текст~~`.
